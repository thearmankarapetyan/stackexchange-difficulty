# How to access and prepare an official community dump

[Documentation home](../README.md) · [Tutorial](../tutorials/first-analysis.md) · [How-to guides](../how-to/access-data-dump.md) · [Reference](../reference/system-reference.md) · [Explanation](../explanation/design-and-scope.md)

> **Goal:** Place the XML files required by a selected processing route in one readable local folder.

**Before starting:** Select the Stack Exchange community, provide enough storage for its
archive, and have an account on that community.

> **1. Open the selected community.** Sign in or create an account on the community that
> supplies the data.
>
> **2. Open dump access.** Go to the profile page, select Settings, and select Data dump
> access under Access.
>
> **3. Review the displayed declaration.** Read and affirm the declaration presented by
> Stack Exchange for dump access.
>
> **4. Download the current archive.** Use Download data and wait for the archive to
> finish downloading.
>
> **5. Extract the archive.** Choose a local source-data folder and unpack the
> downloaded files there.
>
> **6. Check the required XML.** Confirm Posts.xml and Comments.xml for Routes A and B.
> Confirm Posts.xml, Comments.xml, and Votes.xml for Route C.

**Authoritative access page:** [Stack Exchange Help Center — How do I access a data
dump?](https://stackoverflow.com/help/data-dumps)

> **Completion check:** The selected source-data folder contains the XML files required by the chosen route, and the files can be opened for reading.
